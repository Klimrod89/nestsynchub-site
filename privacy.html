Privacy Policy

How Nest Sync Hub handles Google Nest data and user authorization.

1. Overview

Nest Sync Hub is a smart-home integration project that allows authorized Google Nest devices to work with compatible home-automation platforms.

2. Google Account Authorization

Nest Sync Hub uses Google OAuth to request permission before accessing supported Google Nest data.

Nest Sync Hub does not receive or store a user's Google account password.

3. Google User Data Accessed

Nest Sync Hub may access data associated with supported Google Nest devices when the user explicitly grants permission.

The specific data available depends on the permissions requested by the integration and the capabilities exposed through Google's APIs.

4. How Google User Data Is Used

Google user data is used only to provide the smart-home integration functionality requested by the user.

Nest Sync Hub does not use Google user data for advertising or unrelated profiling.

5. Data Storage

Authorization credentials and integration data may be stored only as necessary to maintain the authorized connection between Google Nest and the user's compatible home-automation environment.

6. Data Sharing

Nest Sync Hub does not sell Google user data.

Data is not shared with third parties except where required to provide the integration requested by the user, or where required by law.

7. Data Retention

Data is retained only for as long as necessary to provide the authorized integration or to satisfy applicable legal requirements.

8. Revoking Access

Users can revoke Nest Sync Hub's access to their Google account at any time through their Google Account security settings.

9. Security

Reasonable technical measures are used to protect authorization credentials and integration data.

10. Changes to This Policy

This Privacy Policy may be updated as Nest Sync Hub changes. The current version will always be published on this page.
